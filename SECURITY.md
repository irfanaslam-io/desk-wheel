# Security

Please report security problems **privately**, not in a public issue:

- email **hello@irfanaslam.io** with "Desk Wheel security" in the subject, or
- use GitHub's **Report a vulnerability** button (Security tab), if it's enabled.

Include what you found, how to reproduce it, and which version (Settings › Updates shows it). You'll get a
reply within a few days. Fixes go out through the normal update channels: the in-app updater (signed update
feed) and the Microsoft Store.

Desk Wheel works offline: files are converted on your computer and nothing is uploaded. The only network use
is the update check and, if you said yes, anonymous usage counts (see the README's Privacy section and docs/RELEASING.md).
