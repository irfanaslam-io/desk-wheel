# Contributing to Desk Wheel

Thank you for helping! Bug reports, ideas and pull requests are all welcome. Please be kind and respectful:
everyone taking part agrees to the [Code of Conduct](CODE_OF_CONDUCT.md).

- **Bugs and ideas:** open an issue with your OS (Windows / macOS and version), the Desk Wheel version, what
  you did, and what happened. Screenshots help.
- **Pull requests:** keep each one focused on one change, follow the existing style, and run the tests first:
  `dotnet run --project tests/Wheel.Core.Tests`.
