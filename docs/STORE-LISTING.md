## 6. Submission options

### Restricted capabilities: why `runFullTrust`

```
Desk Wheel is a desktop utility (Win32, .NET) packaged as MSIX. It needs runFullTrust to work as a regular desktop app: it reads the files the user drags onto it or selects in File Explorer and writes the converted copies next to them; runs its bundled converter (FFmpeg, LGPL) as a child process for video and audio; captures the screen when the user takes a screenshot; shows its button and tray icon; and keeps a local clipboard history that the user can turn off. It does not install drivers or services and does not change system settings.
```

### Notes for certification

```
Desk Wheel is a tray utility with no main window. After launch, an orange round button appears at the right edge of the screen and an orange ring icon in the system tray (notification area).

How to test:
1. First launch: a small window asks whether to send anonymous usage counts. Either answer works.
2. Drag an image (for example a .jpg) from File Explorer onto the orange button. A wheel opens around it; release on "PNG". A card in the corner confirms, and the PNG is saved next to the original.
3. Click the orange button: the Screenshot wheel opens. Click "Area", drag over part of the screen, then press Enter. The picture is saved to Pictures\Desk Wheel Screenshots and copied to the clipboard.
4. Right-click a picture in File Explorer > Open with > Desk Wheel: the picture viewer opens; the Left and Right arrow keys move through the folder.
5. Right-click the tray icon for Settings, History and Quit.

No account, sign-in or internet connection is needed. The Store version does not update itself; updates come from the Store. Word, Excel and PowerPoint to PDF needs Microsoft Office or LibreOffice installed; without either, those choices are not shown.
```
